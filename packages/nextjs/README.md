# TradeLayer frontend

Vite + React + wagmi. Three screens:

- **Trade** — seal a buy intent in the browser (ECIES to the enclave key), sign it with the wallet, lock
  company tokens in `OrderEscrow`, hand the sealed envelope to the intake API, watch it settle.
- **Portfolio** — derive the portfolio key from a wallet signature and decrypt the enclave-written
  copy of your positions from `ConfidentialLedger`. Plus public balances of the company token and ATS
  equity tokens.
- **Org admin** — create the HTS company token through the vault, fund the treasury with USDC, grant /
  revoke KYC, freeze / unfreeze, pause — all enforced by the Hedera network.

```bash
yarn start            # http://localhost:8080
yarn check-types && yarn lint && yarn build
```

Set `VITE_BACKEND_URL` if the intake API is not on `http://localhost:8000`.

Contract addresses come from `contracts/deployedContracts.ts` (generated by `yarn deploy`) and
`contracts/externalContracts.ts` (Hedera HTS USDC). The seal library in `src/lib/seal.ts` must stay
byte-compatible with `cre/tradelayer/src/crypto.ts`.
